# Intrasaccular flow disruptor—`OIFM_OIDM_240838`

**Synonyms:** WEB device, WEB embolization device, Woven EndoBridge, Contour Neurovascular System

**Tags:** head, CT, finding

Endovascular device placed within an aneurysm sac to disrupt inflow and promote thrombosis, such as a WEB or other intrasaccular embolization device.
